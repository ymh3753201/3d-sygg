# 零基础：三份提示词完成商业广告制作

教程版本：v2.1.3｜2026-10-04。

**第一份：安装配置 → 第二份：检查确认 → 第三份：执行生成。** API 资料只在第一份提供，第二份直接复制发送，不用再填。第三份上传素材并填写广告需求。

## 一、开始前只做两件事

1. 在 Codex 打开一个工作文件夹，例如“我的商品广告”。三份提示词都在这个项目里发送。
2. 把已有模型资料准备好。暂时没有也可以先发第一份提示词，让 AI 集中指导你补齐。

“请求地址”就是发给哪家服务，“API 密钥”是使用凭证，“模型 ID”是具体模型名称，“接口文档”说明 AI 应该怎么调用。

- **中转站**：提供该站请求地址、模型 ID、密钥安全保存位置和 API 接口文档。文档找不到就向该服务商索取，不能用厂商官方文档代替。
- **官方**：可以提供接口文档，也可以让 AI 联网查该厂商官方资料。
- **Codex 内置生图**：可用时不需要独立图片 API。第一份让 AI 判断；独立图片 API 或新视频服务可能需要额外接入，不能只填 Key 就称能用。

真实密钥只在本机安全保存，不粘贴到公开笔记、群聊或提示词中。注册、登录、充值和系统密码由你本人操作。

## 二、第一份提示词：安装配置

下载：https://github.com/ymh3753201/3d-sygg/releases/latest

备用网盘地址与提取码：待老师补充。不能下载 GitHub 时，从网盘解压后把文件夹路径告诉 AI。

把“填写”换成已有资料，不知道可填“暂无”。内置生图可用时不用填写独立图片 API 信息。复制下面整段发送：

```text
我是零基础学员，请在当前工作文件夹帮我完成「3d-sygg」的下载、安装和模型配置。请实际执行，用简单中文说明，尽量减少我的操作。

仓库：https://github.com/ymh3753201/3d-sygg
下载：https://github.com/ymh3753201/3d-sygg/releases/latest
已下载的网盘包路径：有就填写，没有可留空。GitHub 下载失败时，请指导我从课程网盘下载、解压并提供路径。

【图片模型】
使用方式：Codex 内置生图 / 独立图片 API / 不清楚（保留一项）
内置生图可用时，下面图片 API 信息不用填。
独立 API 服务商及类型：填写名称；官方 / 中转站 / 不清楚
请求地址：填写；官方不知道可让你查
模型 ID：填写；不知道请协助核对
API 接口文档：填写链接或本地文件路径；官方可填“请查官方文档”，中转站须提供该站文档
密钥：填写本机安全保存位置或环境变量名，不粘贴真实 Key

【视频模型】
服务商及类型：填写名称；官方 / 中转站 / 不清楚
请求地址：填写；官方不知道可让你查
模型 ID：填写；不知道请协助核对
API 接口文档：填写链接或本地文件路径；官方可填“请查官方文档”，中转站须提供该站文档
密钥：填写本机安全保存位置或环境变量名，不粘贴真实 Key

【旁白】
默认需要中文旁白；不需要时写“不需要”。需要时请协助配置 MiniMax 语音，缺资料再告诉我补什么。

已有资料我会一次提供；不清楚的可以写“暂无”。请集中问我最少的缺项，不要让我反复填表。若我还没申请模型服务，请根据 Skill 支持的能力协助我选择并查对应服务的申请资料；注册、登录、充值和保存密钥由我本人完成，不自动购买。

请完成：
1. 下载并安装完整 Skill，检查 Python、FFmpeg、ffprobe、cloudflared 等工具。已有版本先备份，保留配置与项目，安装到当前项目 .agents/skills/3d-sygg。
2. 先判断官方还是中转站。中转站必须用我提供的地址、密钥及该站实际模型 ID，按该站接口文档接入；缺文档让我提供，不用厂商官方文档替代、不擅自换站点。官方资料不足时，自行联网查对应厂商官方文档，核对地区、地址、模型和调用方式。
3. 配置可用的生图、视频和需要的旁白能力。已有通道匹配就直接配置；不匹配时先备份，再按真实文档补齐本项目必要适配与检查。独立生图 API 不能只保存 Key 就称接通，不能伪造来源。遇到当前无法支持的能力如实说明。
4. 引导我在本机安全配置密钥，确认执行环境实际能读取。不要显示密钥，不写进公开文件、日志或 Git，不改我的 Codex 登录配置。
5. 先做不计费检查；确有必要做付费验证时，先说明费用、次数、重试上限和素材公开范围，取得我明确同意后执行。不擅自生图、合成语音或生成广告。

保存一份不含秘密的“安装配置记录.md”：记录实际安装位置、模型与服务商、接口类型、非敏感地址、文档依据、密钥读取方式、已做检查与未完成项。最后告诉我安装配置是否完成，以及可以直接发送第二份提示词了吗。
```

这一阶段由 AI 完成安装、补齐资料和接入。遇到需要你操作的地方，按它的简单说明完成即可；不用自己研究命令。

## 三、第二份提示词：检查确认

**不需要填写任何信息，整段复制发送。** AI 应从第一阶段的记录和实际环境检查，不让你重复提供密钥或文档。

```text
请检查当前工作项目的「3d-sygg」是否已经正确安装配置。我是零基础学员，请读取“安装配置记录.md”和实际配置，自行检查，不让我重新填写 API 信息。

请检查：
1. Skill 文件完整、能够被 Codex 识别，所需工具能在实际执行环境运行，输出目录可写。
2. 本次需要的图片、视频和旁白 API 已配置；内置生图无需独立 Key，未使用的供应商无需配置。
3. 密钥能被安全读取，供应商、官方/中转类型、请求地址与模型 ID 对应正确。不显示密钥，不拿一家的 Key 去试别的站点。
4. 图片模型具有所需生图/参考图能力；视频模型具有所需生成、查询与下载能力；旁白按需可用。依对应文档采用不计费检查，不把一次目录查询当成真实生成成功。
5. 整个流程保留方案与参考图两次确认、预算和失败恢复，不存在未完成的必要适配。

能自动修复的常规配置问题请修复，修改前保留备份。只有确实缺资料或需要我本人登录、授权时，才集中告诉我下一步怎么做。
不擅自提交收费生成。必要的付费实测先说明费用与次数并取得同意；已有有效验证可以复用。没实际生成过就明确写“配置检查通过，生成效果未实测”，不能假称实测通过。

输出简短检查结果，并保存 setup-audit.md：哪些通过、哪些待解决、是否具备开始制作的条件、尚未验证的范围。只有本次必需条件满足才告诉我可以发第三份提示词；缺密钥、必要接入未完成或新通道必须验证却未验证时，不判定通过。
```

看到“具备开始制作的条件”再发第三份。看到“待解决”，先按 AI 提示处理。**配置检查通过和真实生成效果通过是两件事**；不能为了检查而偷偷收费生成。

## 四、第三份提示词：执行生成任务

上传商品照片；需要人物出镜时再提供有权使用的成年人物素材。尽量填写广告类型、时长、比例、分辨率。其他内容可以不填，由 AI 在方案里建议。

```text
请使用 $3d-sygg，根据我这次上传的商品或人物素材，执行商业广告制作任务。先读取 setup-audit.md 并检查当前配置；第二阶段未通过时先指出缺项，不直接生成。

【请尽量填写这四项】
广告类型或用途：填写，例如商品带货、品牌展示、人物使用商品演示
成片时长：填写，例如 15 秒
画面比例：填写，例如 9:16 竖屏或 16:9 横屏
分辨率：填写，例如 720p 或 1080p；未填请先按 720p 提案

【素材】
我已上传商品照片；需要人物时也上传有权使用的成年人物照片。
附件无法读取时，请指导我保存到本地并提供路径，不用相似商品替代。

【选填，不填由你先提案】
商品名称、真实卖点、投放平台、风格、广告文字、人物如何出镜、旁白要求、预算上限。
默认中文旁白；无需旁白请写明。不能从照片猜材料、内部结构、功效、价格或销量。

请减少问答，资料足够就先做完整方案。缺少关键要求时一次问清；选填项由你提出建议，交给我在方案阶段确认。人物素材按 Skill 的人物规则处理，保持已批准身份，不擅自公开原照片。模型不支持所需分辨率或时长时先说明可行方案，不静默降低要求或换模型。

执行顺序：
1. 实际查看素材，提案并说明故事、分镜、图文、人物、旁白、时长、比例、分辨率、实际模型、费用及重试上限。等我回复“确认方案，生成参考图”后再生图。
2. 展示真实参考图，检查商品和人物、说明费用与生成参考图临时公开范围。等我回复“确认参考图并生成视频”后再提交视频。
3. 按批准内容生成、剪辑、混音，检查完整成片的画面、文字、动作、实际时长、分辨率和声音。无法实际试听时明确待复核。

中断优先恢复原任务，不重复收费；变更素材、模型或超出预算/恢复额度前取得对应授权。最后给我可播放 MP4、本地保存位置和真实检查结论，不发布到任何平台。
```

### 接下来你只要确认两次

先看完整方案与费用，满意后回复：

```text
确认方案，生成参考图。
```

再看真实参考图，确认商品、人物、费用及素材公开范围都能接受后回复：

```text
确认参考图并生成视频。
```

不满意直接指出要改哪里，不要先确认再修改。AI 完成生成和剪辑后会给你 MP4；打开检查画面、文字和声音，文件不会自动发布。

## 五、遇到问题怎么办？

- 找不到 Skill：让 AI 检查安装位置，必要时重新打开项目。
- 缺接口文档：中转站向服务商索取；官方让 AI 查官方资料。
- 工具或模型不能用：把报错给 AI，不要公开真实密钥。
- 生成中断：告诉 AI“恢复原项目，优先查原任务，不要重复提交”。保留整个项目目录。

源码免费，模型调用可能收费。当前优先使用 macOS；Linux 按环境配置，原生 Windows 未支持。安装工具和 API 接入由 AI 检查，无法支持的能力必须如实说明。
