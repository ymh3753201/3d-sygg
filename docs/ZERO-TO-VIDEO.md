# 零基础教程：用 Codex 安装、检查并制作商品商业广告

教程与分发包版本：**v2.1.1**｜更新日期：2026-10-04｜Skill 名称：**3d-sygg**。

你不用自己写程序。本教程让你依次发送三份提示词，由 Codex 帮你安装、配置检查，再制作广告。你需要完成的操作是：打开工作文件夹、准备自己的 API 资料、上传商品图、确认方案与参考图。

## 一、先弄清楚你要安装什么

Skill 可以理解为“交给 AI 的操作手册与工具包”。3d-sygg 让 AI 按固定流程策划商品广告、生成参考图、调用视频服务、剪辑混音并检查 MP4。它不只是文字提示词，也不是安装完就有一个可双击运行的网页。

本版本在你的电脑和工作项目中运行；没有部署到服务器的必要。视频生成仍由第三方模型服务完成，所以电脑需要联网。源码免费，模型调用可能收费。Codex 的账号或订阅不等于视频供应商的免费额度。

先认识五个词：

- **工作项目**：你在 Codex 中打开的本地文件夹。Skill、配置和生成记录都应在正确项目里。
- **API Key / 密钥**：模型服务的访问凭证，像专用密码，不要发到公开笔记、群聊或 GitHub。
- **Base URL / 请求地址**：程序向哪家服务发送请求。它不是网站首页，也不一定是接口文档地址。
- **模型 ID**：接口接受的精确模型名称。同一个模型在中转站可能有不同 ID，必须照控制台或文档填写。
- **依赖工具**：Python 负责执行流程；FFmpeg/ffprobe 负责剪辑和检查；cloudflared 负责临时 HTTPS 参考图传输。让 AI 检查和安装即可。

## 二、安装前准备好这五样东西

1. 能正常对话、读写工作项目并执行工具的 Codex；生成参考图还需要原生图片查看与可用的生图能力。具体权限与额度以你的环境为准，不能仅凭“官方账号”四个字判断工具一定可用。
2. 一个新工作文件夹，例如“我的商品广告”。在 Codex 添加或打开这个文件夹，进入该项目的新聊天。之后三份提示词都在这个项目里使用。
3. 商品照片，尽量提供正面、侧面和标签清楚的角度；只上传你有权使用的素材。准备真实卖点、投放平台、时长、比例与预算。
4. 自己的视频服务账号与 API 资料；需要中文旁白时还要准备 MiniMax 语音 API。独立生图 API 是否需要，见下面说明。
5. 可连接下载源、模型服务与临时隧道的网络。管理员密码、验证码、注册付款和个人账号登录由你本人完成。

推荐先在 macOS 使用。现有离线程序已在 macOS 和 Linux 自动测试；Linux 使用环境变量保存运行凭据。当前脚本不支持原生 Windows，WSL 需要另外核对 Codex、生图能力和工具环境，不能按安装成功就保证可用。

### 内置生图与独立图片 API，选哪条路？

**路径 A：Codex 内置生图可用。** 当前 Skill 默认走这条路，不需要为 Python 再填一组独立图片 Key。让第二份提示词检查你实际能否调用内置工具。可用性检查不等于已生成过图片，不在检查阶段偷偷消耗生图额度。

**路径 B：你明确要用独立图片 API。** 请提供该服务的地址、Key 安全位置、模型 ID 和接口资料。当前公开版没有通用生图 API 适配器，需要 AI 补齐参考图编辑、生成结果保存和来源追踪；仅填写 IMAGE_API_KEY 不会自动接通。

独立视频官方接口或新的中转站也可能需要适配。**三份提示词会帮助 AI 完成必要接入，但不能替代不存在的接口资料、账号权限或模型能力。** 第二阶段必须如实区分“已经配置”和“已经真实生成验收”，不要在尚未接通时进入生产。

## 五、准备 API 资料：先确认官方还是中转

**官方 API**：你直接在模型厂商的控制台申请并调用其服务。密钥发往该厂商对应区域的官方请求地址。不知道地址或字段时，让 AI 查该厂商官方文档。

**中转 API**：你在另一家服务平台申请密钥，由该平台转发模型请求。调用必须使用这家平台给你的请求地址和密钥，模型 ID 也以这家平台为准。即使它写“OpenAI 兼容”或显示厂商模型名，也不能擅自改成厂商官方地址。

**不知道类型怎么办？** 提供服务商名称、控制台域名和文档，让 AI 给出判断依据；仍无法确认就问服务商。不能用一把中转 Key 试遍多个无关网站。

填写资料时区分三种地址：“账号控制台地址”“API 文档地址”“真正的请求 Base URL”。让 AI 按文档检查是否已有 `/v1` 等路径，避免重复拼接。官网资料不能覆盖中转站自有的创建任务、查询、下载、图片上传、认证和模型命名方式。

### 给 AI 的信息卡（不包含真实密钥）

```text
用途：图片 / 视频 / 旁白
服务商名称：________
类型：官方 / 中转 / 不清楚
控制台地址：________
请求 Base URL：________
模型 ID：________
API 文档链接或本地文件路径：________
Key 已保存在：本机钥匙串服务名 / 运行环境变量名 / 本机私有配置位置
账号区域及必要项目编号：有则填写，没有则留空
```

**真实 Key 只在本机隐藏输入。** macOS 当前内置通道支持钥匙串；Linux 使用环境变量。桌面 Codex 不会自动继承另一个终端后来设置的变量，第二份提示词要验证实际执行环境。当前脚本不会自动读取 `.env`；不要误以为文件存在就算配置好了。不要让 AI 把 Key 写到会上传的仓库、报告或样例里。

若没有完整文档，让 AI 自己联网查找：官方用厂商官方文档，中转先用该中转服务商的文档和示例。不能查不到就凭相似服务拼字段。必要字段包括：鉴权方法、精确模型 ID、生成创建、任务查询、结果下载、参考图传输、时长/画幅/清晰度、声音支持和费用依据。

### 现成通道与新通道的区别

当前代码已有 wxart Omni、沧元 Omni / Seedance / H3 视频和 MiniMax 语音适配。具体 ID 见配置文档。它们是代码中的服务商路线，不是所有同名模型的通用协议，也不是供应商实时可用性保证。

若你用的是课程截图里的另一家中转站，或厂商官方视频接口，需要第二份提示词判断合同是否完全匹配，必要时开发独立适配。不要把厂商官方 Key 填进作者默认中转变量后就称接通。MiniMax 语音 Key 也不等于一定能调用该账号下的视频模型。

### 审查报告应该怎么看？

- **通过**：当前这一项有真实检查证据，例如工具能启动、离线测试通过或认证目录查询成功；查看该项证明的具体范围。
- **待配置**：缺少 Key、地址、文档或依赖。按 AI 指出的最少缺项补齐，再继续。
- **已配置待实测**：已完成代码与非计费检查，但尚未付费生成，不能说画面或声音已合格。
- **不支持**：当前环境或接口无法完成该能力，不能通过静默换服务商来“通过”。

首次接入新通道，可能需要独立小样验证。AI 应先说明调用服务、次数、当前费用或明确未知、金额上限、重试额度与素材公开范围。只有你明确批准后才能做；资料不明就不能假称“零费用测试”。配置审查本身不授权生图、语音或视频生成。

**看到所有需要的能力已就绪，且新通道验证要求满足，再进入广告制作。** 不强制把所有供应商密钥配齐；只配置你选择的视频、按需旁白和必要生图能力。

## 七、发送提示词三：上传商品图，制作第一条广告

建议第一条广告目标清楚、素材清晰，先指定投放平台、时长和比例。时长可以是 15 秒，模型单次上限不等于最终成片上限，AI 会按通道合法参数拆段剪辑。报价和生成段数按你实际使用的服务计算。

在同一个项目聊天上传商品图，修改下面的需求后发送。照片附件无法成为脚本可读路径时，在工作项目另存图片并告诉 AI 路径，不靠文件名猜商品。

```text
请使用 $3d-sygg，根据我这次上传的商品照片制作商业广告视频。先读取当前项目的 SKILL.md 和 setup-audit.md，确认采用我已配置且允许使用的生图、视频与旁白通道。没有审查报告时先做最少必要检查；存在未完成适配、缺密钥或新通道需要实片验证时先说明，不假装已能生产。

商品名称：填写
目标受众与投放平台：填写，例如抖音商品展示
成片时长：填写，例如 15 秒
画幅：填写，例如 9:16 竖屏
想表达的真实卖点：填写；没有就只按照片可见信息设计
广告风格：填写；不知道可由你提出专业方案
画面文字：填写品牌和可用广告语；不知道请先建议
人物要求：无人 / 只出现手 / 成年模特 / 由你建议（保留一项）
旁白：需要中文旁白 / 不需要（保留一项）
预算要求：填写币种和金额上限；不清楚请先列当前费用依据和最多调用次数，等我确认
失败重试：每段最多 1 次额外视频重试；语音和生图额外收费不得超出事先展示并批准的范围
本次商品照片：我已上传；若附件没有可读取本地路径，请指导我保存图片并提供路径

请按 Skill 的两次确认流程执行：
第一阶段：实际查看每张商品照片，记录可确认事实与不确定项，不猜材料、内部结构、成分、功效、价格或销量。设计有明确视觉事件的完整故事、逐镜动作、图文动效、运镜、人物、音乐音效和旁白。根据模型合法时长拆段，保留我的目标成片时长，不静默改成 10 秒。展示方案、实际供应商/模型、画幅、参考图数量、视频与旁白调用次数、费用和恢复上限。此时停止，等我回复“确认方案，生成参考图”；未确认不生图。
第二阶段：收到确认后，生成商品母版、必要人物设定与分镜/关键帧，实际对照商品检查。展示真正待使用的每张图片、上传顺序与作用，说明哪些生成参考图会临时公开给视频供应商。停止，等我回复“确认参考图并生成视频”；未确认不提交视频。图片与产品不符先报告并修正，不把未看过的素材登记为已核验。
第三阶段：收到第二次确认后按批准的素材、模型、费用和有限恢复额度生成视频及旁白，自动剪辑混音。查询/下载失败先恢复原任务；提交结果不明停止新增收费请求；不新建重复广告，不擅自换供应商。方案、图、时长、声音或额度发生实质变化，先展示变化并取得对应授权。
交付前检查完整成片的实际时长、规格、商品与人物身份、镜头顺序、动作、文字、宫格残留和声音，实际观看并试听。无法试听或质量未达标时明确待复核，不把程序检查通过说成广告合格。不要为了通过检查删除批准的创意或旁白。

最后给我可播放 MP4 的本地链接、保存位置、实际时长/规格、请求与恢复记录、真实检查结论及尚需复核的问题。不要发布到任何平台。整个过程使用简单中文，只在真正需要我补信息或确认时停下。
```

## 八、你只需要做两次正式确认

**第一次：确认方案。** 查看真实商品判断、视觉事件、完整故事、逐镜动作、广告语、旁白、比例与时长、实际供应商和生成费用/恢复上限。有问题就在此阶段修改。满意后回复：

```text
确认方案，生成参考图。
```

这会进入生图阶段，生图可能消耗账号额度。不能把此确认当成提前授权视频生成。

**第二次：确认实际参考图。** AI 必须展示真实商品母版、必要人物设定和各段分镜/关键帧。核对标签、外形、商品颜色、人物和画面文字；看不对就说清楚哪里不对。确认实际图片及视频费用、素材临时公开范围后回复：

```text
确认参考图并生成视频。
```

这个确认授权已展示范围内的视频/旁白生成、参考图临时传输与恢复额度。默认每个失败视频段最多一次额外重试，AI 必须在方案中明确可能额外收费。不能以“免费修一下”为名增加未批准调用。

生成后由 AI 做整片技术与实际视听检查，不再增加第三次固定确认。你仍可以看成片提出修改；改动导致额外生图或视频收费、变更模型/素材/旁白时，先说明范围再授权。

## 九、下载成片与遇到问题时怎么做

MP4 默认位于 Skill 的 `outputs/项目编号/` 下，具体最终路径由 AI 提供。打开它检查时长、播放、商品、文字与声音；不要只看一个“成功”字样。AI 无法实际试听时，交付状态必须写“待声音复核”。

保留整个项目目录，因为方案、批准参考图、任务编号、请求账本和音频用于恢复。不要只留下 MP4 后删除生成记录。

- **下载 GitHub 失败**：从备用网盘下载并解压，给 AI 实际路径；不要反复重复安装。
- **找不到 Skill**：让 AI 核对 `.agents/skills/3d-sygg/SKILL.md`、是否多嵌套一层，重新打开项目或重启。
- **Key 不存在、401/403**：核对官方/中转类型、正确请求域名、权限和进程环境，不把 Key 发到公开求助帖。
- **生图不能用**：区分内置工具未开放与独立 API 尚未适配。买了图片 Key 不意味着当前 Skill 自动会调用。
- **查询模型目录失败**：服务可能没有 `/v1/models`，按其文档检查，不盲目换域名。
- **素材传输或隧道失败**：先排查 cloudflared 与网络。原商品照片不能为测试网络而公开。
- **视频中断**：告诉 AI“恢复这个原项目，优先查原任务，不新建重复请求”，并提供项目路径。
- **submission_unknown**：不确定是否已创建/计费，暂停新增收费请求，让 AI 查原任务或指导联系供应商。
- **不满意广告**：指出具体商品、镜头、文字、动作或声音问题，保留原项目。额外收费修改先说明并授权。

## 十、老师维护与学员自检

学员只下载正式分发包，不把自己的 Key、原图、成片和输出账本再打包分享。老师更新时应保留旧版备份在分发目录外，避免学员误装；新分发包包含完整 Skill、三份提示词、这份教程、版本信息与校验清单。

本教程的三份提示词也单独存放在 `docs/prompts/`；网盘分享目录根部有同内容的三个文件。它们必须与本教程一致，不让学员拼接多套过期教程。
