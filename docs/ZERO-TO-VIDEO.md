# 零基础：安装并使用商业广告 Skill

教程版本：v2.1.2｜更新日期：2026-10-04。

你只要依次发三份提示词：**安装 → 检查配置 → 制作广告**。不会写代码也可以照着做，具体命令交给 Codex 执行。

## 一、开始前准备什么？

1. 打开 Codex，新建或打开一个工作文件夹，例如“我的商品广告”。后面的操作都在这个文件夹的聊天里完成。
2. 准备商品图片、真实卖点，以及想做的视频时长和预算。
3. 准备视频 API 资料。需要独立生图 API 或中文旁白时，再准备对应服务的资料。

API 就是让程序使用模型的接口；请求地址表示“发给哪家服务”，密钥是“使用凭证”，模型 ID 是“选哪个模型”。**接口文档告诉 AI 这些东西怎么用，不能漏掉。**

### 官方与中转站，资料怎么准备？

- **中转站用户**：请提供该站的请求地址、密钥安全保存位置、模型 ID，以及 **API 接口文档链接或文件**。文档可在控制台找，找不到就向服务商索取。不能拿模型厂商的官方文档替代。
- **官方用户**：可以自己提供接口文档，也可以填写“请 AI 查官方文档”。AI 会联网查对应厂商的官方资料。
- **不知道是哪种**：提供服务商名称和控制台网址，让 AI 先判断；仍不确定就先确认，不乱试密钥。

密钥不要粘贴到公开笔记或群聊。让 AI 教你在本机安全保存，提示词里只写保存位置。

生图默认使用 Codex 内置工具，是否可用由第二份提示词检查；内置工具可用时，不需要另买图片 API。独立图片 API 或新视频服务可能需要补齐接入，**填写 Key 不等于已经能用**。

看到 AI 说“安装完成”，并说明所需工具已就绪，再进行下一步。需要重启时，重启后重新打开同一个工作文件夹。

## 三、发提示词二：提供资料，检查配置

下面的“填写”换成你的真实服务资料，不知道的写“不清楚”。**中转站的接口文档必须提供；官方接口文档可提供，也可让 AI 查。**

如果使用 Codex 内置生图，图片请求地址、模型 ID、接口文档和密钥位置都可填“不需要”。

```text
我是零基础学员，请检查并帮我配置当前项目的「3d-sygg」，用简单中文告诉我结果。

【生图方式】
Codex 内置生图 / 独立图片 API / 不清楚：保留一项。
如果使用内置生图，请检查工具是否可用，以下图片 API 信息可填“不需要”。

【图片 API 信息】
服务商名称：填写
接口类型：官方 / 中转站 / 不清楚
请求地址：填写
模型 ID：填写
API 接口文档：填写文档链接或本地文件路径
密钥：已在本机安全保存，填写保存位置或环境变量名，不粘贴真实 Key

【视频 API 信息】
服务商名称：填写
接口类型：官方 / 中转站 / 不清楚
请求地址：填写
模型 ID：填写
API 接口文档：填写文档链接或本地文件路径
密钥：已在本机安全保存，填写保存位置或环境变量名，不粘贴真实 Key

【旁白】
需要中文旁白 / 不需要：保留一项。
需要时，请检查 MiniMax 语音配置；缺少服务资料或密钥时告诉我补什么。

请先确认每个接口是官方还是中转站，不确定就问我。
中转站：我必须提供这家中转站的 API 接口文档、请求地址和密钥，模型 ID 也按它的资料填写。资料缺失时请让我补充，不用厂商官方文档代替，不擅自换成官方地址或别的站点。
官方：我可以提供 API 接口文档，也可以在这一栏填“请查官方文档”。资料不完整时，请自行联网查对应厂商官方资料，核对正确的请求地址、模型 ID 和调用方式。

请阅读 Skill 的说明，检查工具、密钥读取和模型接入是否正确。现有通道匹配时直接配置；不匹配时先备份，按正确文档补齐本项目所需适配与检查。独立图片 API 不会仅靠填写 Key 自动接通，不能伪造生图来源，也不能把尚未接通说成可用。
不要显示或上传我的真实密钥，不改我的 Codex 登录设置。先做不计费的检查；需要收费测试时，先告诉我服务商、模型、费用、次数及素材公开范围，等我明确同意。
最后告诉我：哪些已通过、哪些还缺资料、哪些已配置但没实测，以及能否开始制作视频。
```

检查结果看这三件事：是否还缺资料、接口是否接通、是否还需要实测。配置成功不代表视频效果已经验证。需要收费测试时，先看清费用和次数，再决定是否同意。

## 四、发提示词三：上传商品图，制作广告

先上传商品照片，再填写下面的需求并发送。第一条可以先做一个目标明确的短广告。

```text
请使用 $3d-sygg，为我这次上传的商品图片制作商业广告。先查看当前项目的配置审查结果，有缺项先解决，不擅自换服务商或模型。

商品名称：填写
真实卖点：填写；没有就只根据照片可见信息设计，不编造功效
投放平台：填写，例如抖音
视频时长：填写，例如 15 秒
画面比例：填写，例如 9:16 竖屏
风格：填写；不知道请你建议
人物：不出镜 / 只出现手 / 成年模特 / 请你建议
旁白：需要中文旁白 / 不需要
预算上限：填写金额和币种；不清楚请先说明费用
商品照片：我已上传，不能读取时请指导我提供本地路径

请严格按两次确认来做：
1. 先查看商品图并给我完整方案，说明分镜、文字、旁白、实际模型、生成次数、费用和重试上限。等我回复“确认方案，生成参考图”，再生图。
2. 展示真实参考图，让我检查商品是否准确，并说明视频费用及哪些参考图会临时公开。等我回复“确认参考图并生成视频”，再提交视频。
3. 生成后自动剪辑、混音，检查完整成片的商品、动作、文字、时长和声音。无法实际试听时明确标为待复核。

生成中断时优先恢复原任务，不重复收费；超预算、更换素材或模型前先取得对应授权。最后给我可播放 MP4、保存位置和真实检查结果，不发布到任何平台。
```

### 你需要回复的两句话

看完方案，确认满意后回复：

```text
确认方案，生成参考图。
```

看完实际参考图，确认商品准确、费用和素材公开范围都能接受后回复：

```text
确认参考图并生成视频。
```

不满意就直接指出要改哪里，不要先确认再修改。完成后打开 MP4，检查商品、文字、画面和声音；成片默认留在你的工作项目中，不会自动发布。

## 五、遇到问题怎么办？

- 下载失败：改用老师的网盘包，提供解压路径。
- 找不到 Skill：让 AI 检查安装目录，必要时重新打开项目。
- 缺 API 文档：中转站向服务商索取；官方让 AI 查官方资料。
- 生图或视频不能用：把报错给 AI，不要公开真实 Key，也不要反复提交收费请求。
- 生成中断：告诉 AI“恢复原项目，优先查原任务，不要新建重复请求”。保留整个生成项目，不只保留 MP4。

本工具需要自己的模型额度，生图、视频和旁白可能收费。优先使用 macOS；Linux 按环境配置，原生 Windows 当前未支持。工具和权限检查由 AI 完成，系统密码、注册和付款由你本人操作。
