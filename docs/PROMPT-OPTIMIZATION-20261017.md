# 短广告提示词与分段一致性优化记录

2026-10-17 的开发记录。现行单段与多段声音规则参见 [声音规则](../.agents/skills/3d-sygg/references/voice-routing.md)。

## 已完成的变化

1. 保留每段对应分镜与适用的商品/人物参考图。三宫格仍是默认设计方式；段数继续由脚本、目标时长和模型能力决定。
2. 每段的入场、出场及相邻段边界同时进入生图和视频提示词。普通切镜允许改变景别；连续动作可共享同一边界状态，冲突会在准备阶段提示修正。
3. 全片共用文字描述的人声、音乐和环境音，各段只安排自己的台词与动作音效。允许有理由的场景声音变化及多个说话人，不要求音频参考文件，不增加独立配音调用。
4. 单独重做中间段时保留全片声音、段落位置和相邻边界；下一段需要连续动作时，替换段不能擅自改变交接状态。
5. 提示词按参考图职责、身份与美术、边界、逐镜动作、文字和声音组织；重复商品细节合并，台词、动作与图文设计保留。
6. 视频默认通道、备用通道和外部图片接口分别检查已登记的字符或 UTF-8 字节上限。已知超限在付费前拦截；未知上限明确报告，不机械截断、不因此自动增加视频段数。
7. 新项目记 `prompt_design_version=1`；旧项目不自动重写提示词和批准记录。说明已接入 Skill 主流程，用户无需额外填写技术字段。

## 效果边界

本次修复的是提示信息遗漏、各段设计缺少共用约束和提交前缺少长度检查。共享文字描述不能保证独立生成的音色、旋律或人物动作完全相同；没有新增末帧上传或声纹绑定。三宫格能否在具体模型中准确兑现，仍需在现有看图和整片观看试听环节验收。
