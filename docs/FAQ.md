# 常见问题

**装好后能直接双击生成吗？** 不能。请用支持图片查看和执行脚本的 Codex（内置生图或已配置的图片 API） 打开工作项目，并让 AI 使用该 Skill。

**需要生图 API Key 吗？** 内置生图不需要。独立图片服务需要自己的 Key 和接口文档；已支持 OpenAI / Seedream 风格接入，AI 会按实际文档配置，详见配置指南。

**提示密钥不存在？** 检查你选择的供应商变量，确认脚本进程实际继承了环境变量。桌面 Codex 不会继承后来在另一个终端设置的变量；macOS 可用钥匙串配置。不要将 Key 发到 Issue。

**401 / 403 或找不到模型？** 核对供应商、密钥权限、区域与模型名。`check-channel` 只查询目录；目录出现模型不保证实际请求一定成功。

**找不到 FFmpeg / cloudflared？** 确认 `ffmpeg`、`ffprobe`、`cloudflared` 在执行脚本的 PATH 中。终端可找到而桌面进程找不到时，需要修正桌面执行环境的 PATH。

**临时隧道失败？** 检查网络与 cloudflared。不要为测试网络运行付费生产命令；保留已有项目与请求证据后排查。

**视频生成中断了？** 保留原项目，运行 `python3 scripts/commercial_ad.py resume --project outputs/PROJECT`。不要新建同样任务；已有任务会优先查询。`submission_unknown` 表示无法确定是否计费，不能盲目重新提交。

**技术 QA 通过就是广告合格吗？** 不是。还要实际检查商品身份、关键视觉事件、动作、文字和声音。无法实际试听时，应保留待复核状态。

**Windows 可以用吗？** 当前脚本依赖 Unix 文件锁和部分平台工具，未支持原生 Windows。WSL 也需要自行验证工具、环境变量和 Codex 生图能力。

**如何反馈问题？** 提供系统、Python 版本、所选通道、去掉密钥和私有地址的报错，以及复现步骤。不要上传商品原图、客户成片、账本或带签名的下载链接。
