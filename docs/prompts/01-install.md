# 提示词一：下载安装

复制下面整段文字发送给 Codex；有“填写”的位置先换成自己的资料。

```text
我是零基础学员，请帮我在当前工作文件夹安装「3d-sygg」商业广告 Skill。

GitHub：https://github.com/ymh3753201/3d-sygg
下载页面：https://github.com/ymh3753201/3d-sygg/releases/latest
如果 GitHub 下载失败，请让我从课程网盘下载、解压，再提供文件夹路径。
我已下载的文件夹路径：未填写，需要时请问我。

请实际完成安装，检查 Python、FFmpeg、ffprobe、cloudflared 等所需工具。已有旧版先备份，保留我的配置和生成记录。
安装到当前项目的 .agents/skills/3d-sygg，确认 SKILL.md 和完整工具文件都在，并确认 Codex 能找到它。
此阶段不要生图、合成语音或生成视频，不调用收费接口。
最后用简单中文告诉我：装在哪里、是否装好、还缺什么，以及可以发送第二份提示词了吗。
```
