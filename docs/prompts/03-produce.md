# 提示词三：制作广告

复制下面整段文字发送给 Codex；有“填写”的位置先换成自己的资料。

```text
请使用 $3d-sygg，为我这次上传的商品图片制作商业广告。先查看当前项目的配置审查结果，有缺项先解决，不擅自换服务商或模型。

商品名称：填写
真实卖点：填写；没有就只根据照片可见信息设计，不编造功效
投放平台：填写，例如抖音
视频时长：填写，例如 15 秒
画面比例：填写，例如 9:16 竖屏
风格：填写；不知道请你建议
人物：不出镜 / 只出现手 / 成年模特 / 请你建议
旁白：需要中文旁白 / 不需要
预算上限：填写金额和币种；不清楚请先说明费用
商品照片：我已上传，不能读取时请指导我提供本地路径

请严格按两次确认来做：
1. 先查看商品图并给我完整方案，说明分镜、文字、旁白、实际模型、生成次数、费用和重试上限。等我回复“确认方案，生成参考图”，再生图。
2. 展示真实参考图，让我检查商品是否准确，并说明视频费用及哪些参考图会临时公开。等我回复“确认参考图并生成视频”，再提交视频。
3. 生成后自动剪辑、混音，检查完整成片的商品、动作、文字、时长和声音。无法实际试听时明确标为待复核。

生成中断时优先恢复原任务，不重复收费；超预算、更换素材或模型前先取得对应授权。最后给我可播放 MP4、保存位置和真实检查结果，不发布到任何平台。
```
