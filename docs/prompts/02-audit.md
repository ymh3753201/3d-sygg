```text
我是零基础学员。我已安装 3d-sygg，请实际检查、补齐并审查它的环境与 API 配置，目标是能按正确流程制作广告。请读取当前项目的 SKILL.md 和配置文档，用简单中文报告。现在只做配置、代码适配和不计费检查，不直接生成广告。

我的生图方式：Codex 内置生图 / 独立图片 API / 不清楚（请保留一项）
图片服务商及 API 类型：填写名称；官方 / 中转 / 不清楚
图片请求地址：填写供应商给出的 Base URL；内置生图可填“不需要”

图片密钥：已存本机安全位置，填写位置或环境变量名；内置生图可填“不需要”

视频服务商及 API 类型：填写名称；官方 / 中转 / 不清楚
视频请求地址：填写供应商给出的 Base URL；官方未查到可填“请查官方资料”
视频模型 ID：填写实际 ID；不知道请根据我的服务商账号或文档核对，不要猜
视频 API 文档或示例：填写链接或本地文件路径；没有就填“请帮我查”
视频密钥：已存本机安全位置，填写位置或环境变量名
旁白：需要中文旁白 / 不需要旁白（保留一项）；需要时检查 MiniMax 服务类型、区域地址、文档与本机密钥。未提供时请只列缺少项，不擅自关闭旁白。

请执行：
1. 检查 Skill 加载、Python、ffmpeg、ffprobe、cloudflared、PATH、输出目录写入、图片查看能力和生图工具可用性。核对运行脚本的环境，而不只是另一个终端。
2. 每种服务先判断 API 属于官方还是中转，以供应商名称、域名、账号控制台和文档为证据。名称相同、接口长得像 OpenAI，不代表官方。不确定时询问我确认，不把密钥发送到搜索引擎或无关域名。
3. 中转 API：创建、查询、下载和鉴权必须使用我提供的请求地址及密钥，模型 ID 必须按该中转站实际 ID；保留文档要求的路径、版本和参数。先查该中转站官方文档、控制台接口示例或我给的资料。模型厂商的官方资料只能辅助理解能力，不能拿它替代中转字段。查不到必要资料就明确缺少哪些字段，不能编造接口，不擅自切到官方、作者默认站点或另一家中转。不启用我没有授权的备援服务商。
4. 官方 API：优先联网读取对应厂商官方最新文档，核对服务区域、认证、模型 ID、创建/查询/下载、参考图传输、时长、画幅和费用。官方 Key 只发往该服务的正确官方端点，不替换成中转地址。保留所查文档链接与日期。
5. 阅读当前适配代码。已有完全匹配的通道就配置并核验；新供应商、新地址/模型或字段不兼容时，本提示词授权你只在当前项目内先备份，再补齐必要适配与针对性测试，保留原通道、两次确认、预算、任务恢复和素材追踪，不改我的全局 Codex 登录配置。不能仅写一个未被读取的环境变量就称“接入成功”。资料不足或环境能力不支持时如实说明并索取最少必要信息。
6. 生图要单独确认：当前公开版默认 Codex imagegen，没有通用 IMAGE_API_KEY 适配。若内置工具可用就直接使用其权限，不要求另买图片 Key。若我明确选择独立图片 API，按上面的官方/中转规则实现参考图编辑、真实结果落盘、生成关系和合法来源校验；不能只保存 Key，也不能把第三方图片伪装为 codex_imagegen。无法完成时标明尚未接通，给出可行下一步。
7. 密钥优先由本机环境变量或 macOS 钥匙串读取，不回显、不写入方案、请求日志、Git 或测试样例，也不放在进程参数中。没有安全来源时教我在本机隐藏输入。脚本不会自动加载 .env；桌面进程是否继承变量要实际确认。只配置本次所需密钥，无须把所有供应商都配齐。
8. 先做离线测试与文档核对，再做该服务支持的非计费认证/模型目录检查；没有模型目录接口时不强行请求 /v1/models，按其官方检查方式并标明能验证的范围。不发送生成类 POST 来“测试一下”。联网查询成功只代表接口检查成功，不代表实片质量已通过。
9. 需要付费小样验证时，先列出供应商、准确模型、素材是否会公开、拟调用次数、当前金额上限和失败重试次数，等我明确授权后再执行。未授权时保留“已配置，待付费验证”，不可称“完全验收通过”。提交不明优先查原任务，不重复收费。

最后生成不含秘密的 setup-audit.md：每项写“通过 / 待配置 / 已配置待实测 / 不支持”，列出生图、视频、旁白各自的供应商、API 类型、非敏感地址与模型 ID、文档依据、适配改动、检查结果、剩余阻塞及费用边界。所有条件满足再告诉我可以发第三份提示词；不能为通过审查而偷偷换模型、关闭旁白或放宽素材校验。
```
