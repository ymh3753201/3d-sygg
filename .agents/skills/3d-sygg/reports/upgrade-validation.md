# 3d-sygg 升级交付与验证报告

日期：2026-09-29。升级范围：项目本地 Skill 的模型适配、分镜执行、长片时间线、恢复与文档。

## 已完成

- 原来没有 Git 仓库，现已初始化本地版本管理。原始版本提交 `7855473`，回退标签 `baseline-omni-20260929`；升级在 `upgrade/multi-model-long-video` 分支实施。
- 默认继续 Omni；保留完整三宫格、1–4 格范围、原素材上传顺序、人物成年人设策略、三种美术风格与动态广告图文。
- 新增沧元 Seedance 2.0 / 2.5 / MiniMax H3 独立参数合同和执行器。H3 使用 768P / 2K，且不发送未支持的 generate_audio 字段。
- 新增四类分镜执行策略与同一镜头编号映射；不同策略必须保留原动作和图文设计。独立帧由生图工具直接生成，不裁切批准宫格。
- 用户时长优先；未指定时由导演计划填写时长与理由。最终按 30fps 计算，单次模型请求限制与成片时长分开。
- 长片按整片故事分段，保留统一身份/风格、入出场状态；最多两个独立段并行。已计划末帧接续先检查再传播，前段替换后后续段重新核对。
- 剪辑支持不同合法源时长、帧级裁剪、切镜、叠化重叠计算、本地缓存；禁止以低清放大冒充批准画质。
- 长旁白按自然章节分段、同音色语速、统一时间线、缓存复用；已支付章节不因本地拼接失败重做。
- 次数与可选金额上限在 POST 前加锁核验。提交不明立即停止；下载失败恢复原任务；旧 schema 8 不自动迁移或扩大恢复预算。
- 保留原方案与参考图两次确认；不把技术策略选择交给普通用户。
