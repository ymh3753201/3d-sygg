# 商业视觉与导演原则

目标是有原创视觉记忆点的高端商品广告。对标苹果发布会的构图精度、耐克概念片的动作因果、先锋潮流广告的字体与材质实验。不能只在普通棚拍方案末尾加“高级、电影级、8K”。执行 AI 实际查看本次图片；商品类型自由描述，不使用行业白名单或历史商品模板。

## 从商品事实到广告创意

先区分两层：商品结构、Logo、已知功能和指定人物身份要忠实；布景、尺度、光影、图形、字体和节奏可以大胆设计。保真不要求产品静止，也不要求环境写实。母版是身份依据，不是整条广告的美术方向。

在原有字段中完成设计，不新增评分表或用户问卷：

1. 从图中找到最有辨识度的视觉资源：轮廓的几何关系、编织/孔洞/折线等节律、材质反差、配色冲突、真实佩戴或操作姿态。区分图中事实、用户提供信息与未知项；看不清的内部结构不是创意素材。
2. 由使用场景与受众确定一个主要记忆目标。内部比较两个不同的视觉机制，选出更贴近商品且更有辨识度的一个，再向用户展示完整方案；不额外生图，也不让用户先选模板。
3. `big_idea` 写清“哪一项商品特征 → 被转化成什么可见事件 → 观众记住什么”。“展示高级质感”“赋予能量”不能单独成为创意；去掉形容词后仍应能画出关键画面。
4. `style_rationale` 说明采用哪种材质、光影、空间和图形语言，如何服务这个事件。品类提示只帮助判断；不能因为复古就自动慢、科技就自动蓝、美妆就自动粉。
5. `story_arc` 写事件如何被触发、发展和兑现，明确最值得记住的瞬间。可以单镜头完成，也可以跨镜；不是必须排成“静物微距 → 模特摆姿 → 商品定格”的三步。

选定方案之前做一次导演判断：换成另一件商品后故事是否仍几乎成立；是否有一帧值得用作广告封面；主体和环境是否发生了可见的变化；去掉运镜后是否只剩静态摆拍。若答案暴露普通展示，就先改方案，不把问题留给生成模型。不要用关键词数量或“创意分数”冒充质量验证。

## 三种主风格：设计动作而非贴标签

| 主风格 | 应落到画面里的设计 | 节奏与构图 | 易退化成的普通方案 |
|---|---|---|---|
| `chrome_puffy_3d` / 3D 充气镀铬潮酷 | 挤压后回弹的充气字、带惯性的液态电镀图形、透亮流体与撞色立体布景；实体字与商品前后交错 | 明亮高反差色块，前景大字与商品制造尺度反差；弹性蓄力后利落释放 | 产品悬浮转圈，再随意撒粒子 |
| `cyber_holographic_vfx` / 未来赛博全息 | 由真实动作触发的悬浮 UI、图标与文字重组，沿产品几何扩散的环形脉冲；效果有起点、传播路径和结果 | 深色空间加冷蓝/激光青的层级，高速推近后短暂停留读懂商品；图形参与转场 | 无缘由蓝色能量环围着所有商品转 |
| `cinematic_neo_noir` / 新冷调商业电影 | 35mm 颗粒、Chiaroscuro 明暗对照、hyper-detailed macro texture；狭缝光、反射切面、金属字或影子与实物形成张力 | 低饱和深调配局部暖光/锋利轮廓光；快进、骤停、接光与尺度跳变，克制的是元素数量而非事件强度 | 全片慢推、轻转、暖光、淡入文字 |

暗调是赛博与冷调电影的常用空间，不统一覆盖充气镀铬风的明亮撞色。每条广告选择一个主视觉机制，让它在不同镜头演进；辅效果负责层次，不抢商品记忆点。不是每镜塞全部词库，也不是禁止在全片延续同一种有效动效。

## 文字、图标与 VFX 是场景的一部分

积极设计大号 Kinetic Typography、品牌字、图标与物理特效，不把“不要旁白字幕/分镜编号”误解成“不要文字或图形”。优先让批准的短标题参与主视觉事件；用户要求无字或无字概念更有力时可不用，但要在方案理由中交代取舍。不能只在结尾加一行淡入文案。

每个需要图文/特效的镜头写 `shots[].graphics`，与构图、动作和转场一起设计。每个元素只用三个字段：

- `kind`：text / icon / effect。
- `content`：文字精确内容，或图标/特效对象的名称；文字必须在全片 `ad_copy` 中批准。
- `direction`：把材质/字形、大小位置、前后空间关系、触发动作、运动/形变、停留可读时刻与退出写成一条连贯描述。

文字可以从商品后方挤出、在前景短暂掠过后让出主体、绕空间翻面或参与形状匹配；不要始终贴屏幕底边。图标可以从已验证的结构/功能概念提炼，并以压印、线框或全息方式出现。装饰符号不能伪装成认证章、真实检测读数、性能参数或不存在的功能。

商品与图形可以前后穿插；关键辨识/读字时刻必须完整看清 Logo、结构和人物脸部。图形可形变，商品本体不被无意改款。展示真实爆炸图、内部零件或拆装前必须有相应结构证据；证据不足时，用外部图形、轮廓切面、投影和空间解构承载同样的视觉冲击，不编造内部机械。

广告文案数量按总时长和阅读节奏决定，没有固定三条上限。文案应短而准确；同一标题只在设计指定的镜头出现，不把全片文案清单铺到每格。图文设计共用一份记录，进入导演审阅、生图和视频提示词，禁止另写一份导致内容或动作丢失。

## 镜头、材质与声音的具体写法

`action` 写起态 → 触发 → 可见结果；`camera` 写起点/终点景别、运动方向和速度变化；`transition` 写前后镜头接续的形状、位置或动势。用 duration_weight 表达节奏差异，不平均分配每格时长。短促冲击、停顿读图和动作释放形成对比；连续慢推和连续 Crash Zoom 都会失去力量。

可描述的节奏特征：Crash Zoom 快速微距推拉、运动方向延续的 Match Cut、卡点平移、空间中的大字穿插。采纳这些特征，不机械复制创作者，也不为了快而牺牲商品理解。

精准词必须带对象和动作，例如：

- `liquid mercury chrome` 描述的外部图形沿商品轮廓汇聚，不能把真实皮革改成金属。
- `inflatable jelly bounce` 描述立体字受挤压、延迟回弹和回稳，而不是给硬质商品本体加果冻形变。
- `frosted acrylic` 用于 UI 面板或布景时，明确透光与主体的遮挡关系。
- `volumetric light scatter`、`chromatic dispersion` 指定光源、介质与边缘位置，不模糊冲淡材质。
- `radial shockwave ring`、`floating holographic runes`、`particle disintegration` 写谁触发、朝哪走、怎样收束，不凭空堆叠。

`Octane render / Unreal Engine 5 style / 8K` 只表达适用的美术目标；输出规格仍以 720p 合同为准。不存在加这些词就自动专业的保证。

在每段现有 `sfx` 中把可听事件与镜头动作对应：压缩时蓄力、碰撞/骤停时短促卡点、转场时有方向的掠过，读图时留声场空间。不强制全片重鼓。Omni 保留无对白、无人声约束；中文旁白仍由 MiniMax 单条合成。

## 方案与实片的验收边界

首次确认前，方案应展示最有冲击力的画面、它与商品的关系、文字/图标怎样动、人物为什么出现及节奏如何推进。所有这些使用现有方案字段与逐镜图形描述，不新增用户审批。

技术 QA 只能验证媒体；创意复核必须对照方案中的标志性事件，观看运动、文字/图标、商品/人物和转场，并试听。不能只看有没有商品、有没有文字就判断“专业”。没有兑现创意时如实待复核，不自动付费重做。

[DeepMind 官方提示指南](https://deepmind.google/models/gemini-omni/prompt-guide/) 明确支持文字的字体、位置、动画和与画面节奏同步，以及故事分镜。当前 wxart 别名的具体兑现程度仍须实测；官方支持不是每次文字准确的保证。
